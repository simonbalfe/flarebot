# AI Elements

Conversation, Message, Tool, Confirmation and Shimmer, copied from [Vercel AI Elements](https://github.com/vercel/ai-elements) (Apache 2.0, see `LICENSE`) and adapted for flarebot:

| AI Elements | Here |
| --- | --- |
| Vercel AI SDK message and tool types | flarebot's transcript types |
| lucide icons | Phosphor icons |
| Streamdown for Markdown | `react-markdown` with GFM |
| `motion` for the shimmer | The `fb-shimmer` CSS animation |
